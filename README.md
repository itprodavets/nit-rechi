# Нить речи

Личное приложение для чтения, упражнений и разговорной практики. Начать можно с текстов, заданий, ссылок или заметок из Anki.

## Запуск

Запусти из папки приложения:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Открой [Нить речи](http://127.0.0.1:4173/). Разрешение на микрофон браузер запрашивает при первой записи. Для озвучки используются доступные на устройстве голоса.

## Первое занятие

1. В кабинете выбери язык. Если пользуешься Anki, импортируй текстовый экспорт заметок и укажи колонки слова, значения и примера.
2. В «Материалах» вставь текст, загрузи файл .txt или .md, добавь упражнение или ссылку на аудио или видео. Для упражнения можно указать ответ, который откроется по запросу во время практики.
3. На карте создай тему. К ней можно привязать материалы из библиотеки и слова из Anki. Кнопка подготовки запроса копирует выбранные слова и их контексты для ChatGPT. Ответ можно сохранить в теме вместе с другими примерами.
4. Прочитай или прослушай материал. Перейди к пересказу или выполнению упражнения, ответь вслух и при желании запиши себя. Отметь, удалось ли ответить самостоятельно. Это назначит следующее повторение.

Слова, темы и результаты хранятся в браузере. Последняя запись для каждого упражнения хранится в IndexedDB. Используй тот же браузер и адрес, чтобы вернуться к своим данным. Приложение импортирует текст заметок, а для оценки устной практики использует твои отметки.

## Перенос из своего чата с ИИ

Открой «Материалы» → «Из чата с ИИ» → «Копировать команду для чата». Если хочешь передать конкретный текст или ссылку из библиотеки, нажми «Взять в чат» на материале. Вставь команду в свой чат и попроси вернуть nit-rechi.json.

В «Из чата с ИИ» выбери тему и загрузи файл или вставь JSON. Пакет добавит слова, контексты, диалоги и упражнения. Если выбрана «Тема из файла», приложение использует одноимённую тему на активном языке или создаст её. Повторный импорт сохранит существующие карточки и материалы. Для переноса API-ключ не нужен.

Файлы в корне можно разместить на статическом HTTPS-хостинге. У каждого адреса сайта своё браузерное хранилище.
